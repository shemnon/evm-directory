Notes 3#

Header fields carrying something other than their Ethereum meaning#

A header field's name is not its meaning. blobGasUsed alone has five: mainnet's blob gas, OP Stack's DA footprint, Avalanche's pinned zero that rejects any other value, Sonic's pinned zero from which BLOBBASEFEE = 1 is derived, and Mantle's DA footprint which — uniquely — DRIVES THE BASE FEE. extraData carries Linea's and Scroll's data, Sonic's block timing (feeding the next block's base fee), Arc's 8-byte required child base fee, and Mantle's 17-byte 1559 parameters. Taiko puts the block's zk gas in difficulty and recomputes it at import, breaking the near-universal post-merge difficulty == 0 test. Two rows change the field COUNT: Sonic's header is a 19-item RLP list with no parentBeaconBlockRoot and no requestsHash while its EVM is Prague, and Berachain's is 22 items — the extra one a 48-byte proposer public key, proven by reconstructing the block hash. Scroll's seal rides inside extraData, is stripped over RPC, and is excluded from Header.Hash(), so the block hash does not commit to the signature authorising the block. Reading a header by JSON key name is not a portable operation.

A second resource meter, and five ways it fails your transaction#

Gas is no longer the only thing a transaction can run out of, and the failure modes share nothing. Taiko's zk gas (100M per block) truncates the block: the offending transaction and every one after it are dropped and the block stays valid, with no eth_estimateZkGas to predict it. Linea and Polygon zkEVM discard with no receipt — no revert, no charge, and on Polygon the hash is blacklisted from the pool. Moonbeam meters four resources (gas, Weight ref_time at a compile-time 25,000 ps/gas, PoV proof size at gas/8, storage growth at gas/366) and the last two fail as OutOfGas with EVM gas remaining. MegaETH halts, refunds the remaining gas, and mines a status: 0 receipt. Sonic inverts the idea: it charges 10% of the gas you did NOT use, verified live to the wei, while eth_estimateGas returns the true figure — so padding an estimate transfers value. A transaction can be rejected, truncated away, silently dropped, or charged for work it never did, and only one of those five is visible as an ordinary revert.

What the EVM does when the gas token is not a native 18-decimal asset#

msg.value, BALANCE, SELFBALANCE, CALL's value argument and eth_getBalance all assume one native 18-decimal asset, and four rows here break that assumption four ways. Celo keeps a native token and pays gas in an ERC-20 via a custom tx type. Mantle makes an ERC-20 the native token, needing no new type at all. Arc makes USDC native at the cost of a duplicated unit — USDC.balanceOf(a) == eth_getBalance(a) // 10**12, integer division, so every account carries sub-microdollar dust the token interface can neither see nor move, and one transfer emits two Transfer logs with two different amounts. Tempo deletes the native asset outright: value != 0 is rejected at admission, BALANCE and SELFBALANCE return 0, the base fee is denominated in attodollars rather than any token — and eth_getBalance returns a FABRICATED CONSTANT for every address at every block, ignoring both arguments, so the RPC and the EVM contradict each other about the same account in the same block. Gnosis is the control at the other end: a different gas token, mainnet's 1559 parameters to the digit, and the base fee credited to a collector rather than burned. Plasma is the null result — its zero-fee stablecoin path is ERC-4337, not consensus, and 0 of 274 sampled transactions paid a zero gas price.
