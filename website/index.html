EVM-intel

EVM differences across major EVM chains, stated as deltas against Ethereum Mainnet.

Axes#

EIP activation set

Which EIPs are live on each chain, stated against mainnet at that chain's baseline fork.

Precompiles

Every precompile address in the dataset, per chain and per address.

Transaction types

EIP-2718 type bytes per chain, and transactions carrying no type byte.

Cryptography

Which algorithms can authorize a transaction, and which have a precompile that verifies them.

Opcodes

The full instruction set per chain, and execution environments that are not the EVM.

System contracts

Real bytecode at fixed addresses: predeploys, genesis allocs and client-installed code.

Fees & envelope

Metering and fee markets per chain, and header fields that differ from mainnet.

Lineage

Code ancestry and fork ancestry, tracked separately.

Silent divergences

Entries that produce a wrong result with no revert, no error and no signal.

Reference

The schema the dataset is written in, and how the site is built.
